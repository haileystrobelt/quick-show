QUICK SHOW — ANDROID INSTALL

A PWA must be served from an HTTPS website to install as an app. Opening index.html directly from Files will not enable installation or offline caching.

EASY HOSTING WITH GITHUB PAGES:
1. Create a new GitHub repository (preferably private data is NOT placed in the source).
2. Upload the contents of this folder to the repository root. Do NOT put your personal information in the HTML file; enter it in the app after installation.
3. Repository Settings > Pages > Build and deployment > Deploy from a branch > main / (root) > Save.
4. Open the HTTPS Pages URL on your Android phone in Chrome.
5. Chrome menu (three dots) > Install app (or Add to Home screen).
6. Open Quick Show from your home screen, then use Edit to enter your information.

IMPORTANT: Information is stored locally in Chrome/app site storage on this device, not synced or backed up. Clearing site data or uninstalling can erase it. Images may be limited by storage quota. Do not use GitHub Pages source files to store private information.
